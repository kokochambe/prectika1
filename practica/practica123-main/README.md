# 🛠️ Информационная система специалиста отдела ТОиР

Система управления техническим обслуживанием и ремонтом оборудования на Django.

## 📋 Описание

Информационная система предназначена для автоматизации работы отдела технического обслуживания и ремонта (ТОиР) оборудования.

## 👥 Роли пользователей

| Роль | Техническая роль | Возможности |
|------|-----------------|-------------|
| **admin** | Начальник ОТК / Администратор | Все заявки, пользователи, отчёты, настройки, аудит |
| **engineer** | Специалист ОТиР | Создаёт планы ТО, назначает задачи, анализирует простои |
| **technician** | Рабочий / Слесарь-ремонтник | Видит только свои наряды, меняет статус, отмечает выполнение |
| **storekeeper** | Кладовщик | Склад запчастей, заявки на выдачу, остатки, предупреждения |
| **trainee** | Ученик / Практикант | Read-only: справочники, чек-листы, просмотр выполненных нарядов |

## 🚀 Быстрый старт

1. **Установка зависимостей:**
```bash
pip install django pillow
```

2. **Применение миграций:**
```bash
python manage.py migrate
```

3. **Создание тестовых пользователей:**
```bash
python create_users.py
```

4. **Запуск сервера:**
```bash
python manage.py runserver 0.0.0.0:8000
```

5. **Откройте в браузере:** http://localhost:8000/

## 📊 Модели данных

### Accounts (Пользователи)
- Custom User модель с ролями
- Отделы, телефоны, статус активности

### Equipment (Оборудование)
- Реестр оборудования с инвентарными номерами
- Статусы: в эксплуатации, на обслуживании, неисправно, списано
- Графики технического обслуживания

### WorkOrders (Наряды-заказы)
- Типы работ: плановое ТО, аварийный ремонт, модернизация, инспекция
- Статусы: новый, назначен, в работе, ожидание запчастей, выполнен, отклонен
- Приоритеты от критического до отложенного
- Отчёты о выполненных работах

### Inventory (Склад)
- Запчасти с артикулами и категориями
- Контроль остатков и минимальных запасов
- Заявки на выдачу запчастей

## 🎯 Функционал по ролям

### Администратор
- Полный доступ ко всем разделам системы
- Управление пользователями и правами
- Просмотр всей статистики и отчётов

### Инженер ОТиР
- Создание и назначение нарядов
- Планирование технического обслуживания
- Анализ простоев оборудования

### Техник
- Просмотр назначенных нарядов
- Изменение статуса выполнения
- Отметка о выполнении работ

### Кладовщик
- Управление складом запчастей
- Обработка заявок на выдачу
- Контроль минимальных остатков

### Практикант
- Режим только для чтения
- Изучение справочников и чек-листов
- Просмотр выполненных нарядов

## 📝 Примечание

Проект создан на основе предоставленной схемы базы данных MS SQL Server и адаптирован для Django ORM с использованием SQLite для разработки.
